# 使用内容寻址的不可变快照

资料库采用 Commit → Directory → File → Block 的不可变对象图，SQLite 只保存用户、令牌、资料库和 Head 等可变元数据。SHA-256、RFC 8785 规范 JSON 和固定 4 MiB 分块让增量传输、历史、完整性校验和并发发布共享同一模型；代价是编码、Unicode、路径状态和对象 Version 一经发布就成为协议兼容性约束。

考虑过整文件上传和内容定义分块。整文件上传无法高效恢复大文件局部修改；CDC 实现和调优成本在没有真实工作负载数据时不成立。固定分块在真实去重率或传输成本证明不足后再重新评估，变更必须使用新的 HTTP 主版本。
